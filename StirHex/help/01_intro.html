1. はじめに

StirHex とは

StirHex は、ファイルの内容を 16 進数と文字で表示・編集する Windows 向けのバイナリエディタです。ファイルの読み込み、保存、編集、検索、比較、印刷などの機能を備えています。

StirHex は、BinaryEditor Stirling Version 1.31 をリバースエンジニアリングにより解析し、現行の開発環境向けに再構築した非公式の移植版です。原作者が公開またはサポートする製品ではありません。原版の著作権は原作者であるＤＤＳ２氏に帰属します。

StirHex は非営利かつ無保証です。本ソフトウェアの利用によって生じた損害について、開発者および原作者は責任を負いません。権利関係と免責事項は、リポジトリ直下の NOTICE.md を確認してください。

移植版では、原版とすべての動作が一致することを保証しません。確認されている差異は 8. 原版との差異 にまとめています。

動作環境

StirHex を動かすために必要な環境は次のとおりです。

項目内容
OSWindows 向けの GUI アプリケーションです。
アーキテクチャ64 bit（x64）版と 32 bit（Win32）版があります。
文字セットUnicode です。
ランタイムMFC と C/C++ ランタイムを静的リンクしています。Visual C++ ランタイムや MFC の追加インストールは不要です。

同梱ファイル

配布物の実行フォルダーには、次のファイルとフォルダーを置きます。

ファイル名説明
StirHex.exeStirHex 本体です。
help\ヘルプフォルダーです。index.html と各章の HTML を入れます。

Struct.def は同梱物ではなく利用者が用意するファイルです。StirHex.exe と同じフォルダーに置くと構造体編集で読み込まれます。置かない場合は定義が読み込まれないだけで、エラーにはなりません。書式は第 5 章で扱います。

インストール

インストーラはありません。StirHex.exe と help フォルダーを、実行する場所へ手動で配置します。

ヘルプを表示するには、help フォルダーを StirHex.exe と同じフォルダーに置き、そこへ index.html と各章の HTML を入れます。StirHex は実行ファイルのフォルダーから help\index.html を組み立てて開きます。ファイルがない場合は、エラーメッセージが表示されます。

設定の保存先

設定は設定ファイル StirHex.ini へ保存します。形式は [セクション] と キー=値 の行からなる INI 風のテキストで、文字コードは UTF-8（BOM なし）です。テキストエディターで開いて内容を確認できます。

保存先は次の順で決まります。先に決まったものを使います。

  1. コマンドラインで /ini:<パス> を指定した場合は、そのパス
  2. StirHex.exe と同じフォルダーに StirHex.ini が 存在する 場合は、そのファイル
  3. 上のどちらでもない場合は %APPDATA%\StirHex\StirHex.ini

2 を「存在する場合」の判定にしているのは、書き込みできない場所へ置かれたときに、書けないパスを保存先にしないためです。実行フォルダーへ設定をまとめる（持ち運ぶ）場合は、空の StirHex.ini を StirHex.exe と同じフォルダーへ置きます。

/ini: は -ini: とも書けます。ini の大文字小文字は区別しません。相対パスを指定した場合は、実行時のカレントフォルダーからの相対位置になります。

使用中の設定ファイルのパスと、それが上のどの規則で決まったかは、[設定]→[環境設定] の [ファイル]ページで確認できます。詳細は 6. 環境設定 で扱います。

アプリケーション全体の設定、拡張子別設定、ファイル履歴、実行履歴、キャレット位置、マークの自動復元記録は、この設定ファイルの各セクションへ保存されます。変更は、環境設定・拡張子別設定の確定時、操作の合間、アプリケーションの終了時に書き出されます。

設定ファイルを読み込めなかった場合は、メッセージを表示したうえで既定の設定で起動します。その起動では設定ファイルへ書き戻しません。内容を確認して直せるように、読めなかったファイルをそのまま残すためです。

バージョン 1.1.0 までは、設定をレジストリキー HKEY_CURRENT_USER\Software\StirHex\StirHex へ保存していました。設定ファイルがまだ無い状態で起動したときに限り、このキーの内容を読み込んで設定ファイルへ引き継ぎます。引き継いだ後も、旧バージョンへ戻せるように、このキーは削除しません。

アンインストール

設定も削除する場合は、次の手順を実行します。

  1. StirHex を終了します。
  2. StirHex.exe と help フォルダーを手動で削除します。
  3. 使用していた設定ファイル StirHex.ini を削除します。場所は上の探索順のとおりです。 %APPDATA%\StirHex フォルダーを使っていた場合は、フォルダーごと削除します。
  4. バージョン 1.1.0 以前を使っていた場合は、レジストリエディターで HKEY_CURRENT_USER\Software\StirHex\StirHex を削除します。

実行ファイルと help フォルダーだけを削除した場合、設定ファイルとレジストリキーは残ります。
