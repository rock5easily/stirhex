# 2. 基本操作

この章では、StirHex の画面の見方と、データを確認・編集する基本操作を説明します。

## 画面構成

StirHex のメインウィンドウは、複数のドキュメントウィンドウを扱う MDI 構成です。
主な部分と表示の切り替え方法は次のとおりです。

| 部分 | 表示する内容 | 表示の切り替え |
| ---- | ---- | ---- |
| タイトルバー | アプリケーション名とアクティブなファイル名を表示します。変更中は末尾に `*` が付きます。 | ファイルを開くと表示されます。 |
| メニューバー | `ファイル`、`編集`、`検索・移動`、`設定`、`ウィンドウ`、`ヘルプ` を表示します。 | 常に表示されます。 |
| ツールバー | ファイル操作、キャレット移動、編集、検索などのコマンドボタンを表示します。 | `[設定]→[環境設定]` の `ツールバーの表示` で切り替えます。 |
| ステータスバー | メッセージ、キャレット位置、変更状態、編集モード、データサイズ、文字セットなどを表示します。 | `[設定]→[環境設定]` の `ステータスバーの表示` で切り替えます。 |
| ドキュメントウィンドウ | アドレス、16進データ、文字データを表示・編集します。 | `[ファイル]→[新規作成]` または `[ファイル]→[開く]` で開き、`[ファイル]→[閉じる]` で閉じます。 |
| アウトプットペイン | `BGREP` の検索結果を一覧表示します。 | `[設定]→[アウトプット]` で表示／非表示を切り替えます。初期状態は非表示です。 |
| ビットイメージバー | 文書のバイト列を、1バイト1ピクセルの画像として表示します。 | `[設定]→[ビットイメージ]` で表示／非表示を切り替えます。初期状態は非表示です。 |
| 構造体編集バー | 構造体名、先頭アドレス、移動ボタン、メンバー一覧、構造体編集ステータスを表示します。 | `[編集]→[構造体編集]` または `[設定]→[構造体編集]` で表示／非表示を切り替えます。初期状態は非表示です。 |

ツールバーとステータスバーは、初期設定では表示されます。表示項目の並びは、同じ
`環境設定` の `ツールバー` ページと `ステータスバー` ページで変更できます。

ドキュメントウィンドウのタイトルは通常ファイル名です。`ドキュメントのフルパス表示`
を有効にすると、タイトルにフルパスが表示されます。変更後に保存すると、タイトル末尾の
`*` が消えます。

## 表示領域とキャレット移動

ドキュメントウィンドウのデータ領域は、左からアドレス領域、16進領域、文字領域の3つに分かれます。

- アドレス領域には、各行の先頭バイトのアドレスを表示します。見出しは `ADDRESS` です。
- 16進領域には、1バイトを2桁の16進数で表示します。上部には列番号のルーラーがあります。
- 文字領域には、現在の文字セットで解釈した文字を表示します。上部には文字列側のルーラーがあります。

アドレス領域は表示専用です。キャレットを置いて入力できる領域は、16進領域と文字領域です。
アクティブな領域はキャレットの形と入力先に反映されます。

### 既定のキャレット操作

次の表は、初期状態のキー割り当てでの動作です。

| キー | 動作 |
| ---- | ---- |
| `←`／`→` | 1バイト左／右へ移動します。 |
| `↑`／`↓` | 同じ列の前／次の行へ移動します。 |
| `Home` | 現在行の先頭バイトへ移動します。 |
| `End` | 現在行の末尾バイトへ移動します。 |
| `PageUp` | 表示できる行数分、上へ移動します。 |
| `PageDown` | 表示できる行数分、下へ移動します。 |
| `Tab` | アクティブな入力領域を16進領域と文字領域の間で切り替えます。 |

`Home`、`End`、`Insert`、Shift 付きの移動キーはキーアサインを経由します。キーアサインを
変更した場合、これらのキーの動作は変わります。この章の説明は既定のキー割り当てに基づきます。

キー割り当ては `[設定]→[環境設定]` の `キーアサイン` ページで変更できます。
`初期設定` を使うと、既定のキー割り当てに戻せます。

### 範囲選択

既定のキー割り当てでは、次の操作で範囲を選択できます。

- `Shift+←`／`Shift+→` で、隣のバイトまで選択を広げます。
- `Shift+↑`／`Shift+↓` で、同じ列の前後の行まで選択を広げます。
- `Shift+Home`／`Shift+End` で、現在行の先頭／末尾まで選択を広げます。
- 16進領域または文字領域をクリックすると、そのバイトへキャレットが移動し、クリックした領域がアクティブになります。
- `Shift+クリック` では、現在の選択のアンカーからクリック位置まで選択を広げます。
- 左ボタンを押したままドラッグすると、通過した範囲を選択します。表示領域の端へドラッグすると、端方向へスクロールします。

選択を広げない通常の移動では、既存の選択は解除されます。選択中のデータは、設定により16進領域と文字領域の
両方、またはアクティブな領域だけが反転表示されます。

## データの入力

入力は、アクティブな領域によって処理が変わります。編集禁止中は、どちらの領域でも入力できません。

### 16進領域への入力

16進領域では `0`～`9`、`A`～`F`、`a`～`f` を入力できます。それ以外の文字は入力されず、
ビープ音が鳴ります。

1. 最初の16進数字を入力すると、上位ニブルを書き込みます。下位ニブルは `0` になります。
2. キャレットはそのバイトにとどまり、下位ニブルの入力待ちになります。
3. 次の16進数字を入力すると、下位ニブルを合成して1バイトを確定します。
4. バイトの確定後、キャレットは次のバイトへ進みます。

入力途中でキャレットを移動したり、別の領域をクリックしたりすると、下位ニブルの待機状態は解除されます。

選択中に16進数字を入力すると、選択範囲は上位ニブルを入力した1バイトに置き換わり、下位ニブル待ちになります。

### 文字領域への入力

文字領域では、入力された文字を現在のキャラクターセットに合わせたバイト列へ変換してから、
挿入または上書きします。文字が2バイトへ変換される場合は、2バイトのデータとして扱います。

IME で確定した全角文字は、文字領域で受け付けます。Unicode の入力文字は入力境界で CP932 の
コードへ変換し、その後に現在のキャラクターセットへ変換します。16進領域で全角文字を確定すると、
入力は受け付けられずビープ音が鳴ります。

キャラクターセットは、次のメニューから文書ごとに選択します。

`[設定]→[キャラクターセット]`

選択できる項目は `ASCII`、`SHIFT-JIS`、`EUC`、`Unicode`、`UTF-8`、
`EBCDIC`、`EBCIDK` です。`UTF-8` は移植版で追加した項目です。
キャラクターセットを変更すると、文字領域の表示と文字入力の
変換方法が変わります。ファイルを開いた直後の入力領域は、拡張子別設定の
`ファイルオープン時に文字入力モードとする` で決まります。

## 上書きモードと挿入モード

入力時の編集モードには、上書きモードと挿入モードがあります。

| モード | 入力時の動作 |
| ---- | ---- |
| 上書き | キャレット位置の既存データを、入力したデータで置き換えます。 |
| 挿入 | キャレット位置に入力したデータを挿入し、既存データを後ろへ移動します。 |

ファイルを開くときの初期モードは、拡張子別設定の `ファイルオープン時に挿入モードとする`
で決まります。初期値では上書きモードです。既定のキー割り当てでは `Insert` でモードを切り替えます。

現在のモードはステータスバーに `上書` または `挿入` と表示されます。モードを切り替えると、
キャレットの形も切り替わります。

上書きモードでデータ末尾へ入力する場合は、`上書きモード時の末尾自動挿入` の設定が適用されます。
有効な場合は末尾への入力が追加になります。無効な場合は、末尾では入力を拒否し、末尾をまたぐ多バイト入力は収まる分だけ上書きします。

`Backspace` と `Delete` の削除動作は、上書きモードと挿入モードで共通です。

| キー | 動作 |
| ---- | ---- |
| `Delete` | キャレット位置の1バイトを削除します。キャレットは同じ位置に残ります。 |
| `Backspace` | キャレット直前の1バイトを削除し、キャレットを1バイト前へ移動します。 |

選択中は、`Delete` と `Backspace` のどちらでも選択範囲を削除し、範囲の先頭へキャレットを移動します。
データの先頭で `Backspace`、末尾で `Delete` を押した場合は削除されず、ビープ音が鳴ります。

## 元に戻すとやり直し、保存

### 元に戻すとやり直し

`[編集]→[元に戻す]` は直前の編集を取り消します。
`[編集]→[やり直し]` は、取り消した編集をもう一度適用します。

Undo/Redo の対象は、入力、1バイトの挿入・上書き・削除、範囲削除、範囲置換、範囲の初期化、
貼り付けなど、データを変更する操作です。Undo と Redo は逆操作の履歴をそれぞれ保持します。

Undo 中は逆操作を Redo 側へ、Redo 中は逆操作を Undo 側へ積みます。新しい編集を行うと、
その時点より後の Redo 履歴は破棄されます。

Undo/Redo が保持する退避データには上限があります。初期値は 256 MB です。上限を超えた場合は、
古い Undo 履歴から、次に古い Redo 履歴から破棄します。各履歴の最後の1件は残します。
上限の値は `[設定]→[環境設定]` の `編集1` ページにある `メモリ上限` で変更できます。
チェックを外すと上限を設けません。

1回の操作だけで必要な退避量が上限を超える場合、移植版では確認メッセージを表示します。
続行すると、その操作は元に戻せず、既存の Undo/Redo 履歴も破棄されます。キャンセルするとデータは変更されません。

### 編集前に戻す

`[編集]→[編集前に戻す]` は、保存済みファイルを読み直して、保存後の編集内容を破棄します。
変更済みで、ファイル名があり、編集可能な場合に実行できます。実行前に確認メッセージが表示されます。

### 保存

`[ファイル]→[上書き保存]` は現在のファイルへ保存します。
`[ファイル]→[名前を付けて保存]` は、指定した別のファイルへ保存します。

保存に成功すると、現在の内容が保存点になり、変更状態が解除されます。タイトルバーの `*` も消えます。
`[設定]→[環境設定]` の `保存時にアンドゥバッファをクリアする` を有効にすると、
保存成功時に Undo/Redo 履歴もクリアされます。

### 編集禁止モード

`[編集]→[編集禁止]` で編集可能と編集禁止を切り替えます。編集禁止中はステータスバーに
`編禁` と表示され、入力、削除、貼り付け、Undo、Redo などのデータ変更操作は実行できません。

ファイルを開くときの初期状態は、拡張子別設定の `ファイルオープン時に編集禁止とする` で決まります。
ロック状態の文書は、`編集禁止` で切り替えられません。
