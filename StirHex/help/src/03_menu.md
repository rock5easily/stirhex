# 3. メニューリファレンス

この章では、文書を開いているときに表示されるメニューを説明します。メニュー名と項目名からは、
キーボード操作のための記号を省略しています。

文書を開いていないときは、編集や文書操作に関する項目が減ります。以下の表は、文書を開いている
ときのメニューの並びです。

ショートカット欄は、初期状態のキー割り当てで確認できたものだけを記載しています。キーアサインを
変更すると、ショートカットは変わることがあります。`-` は、このメニュー項目に対応する既定の
ショートカットを確認できなかったことを示します。

メニュー項目が無効な場合は、必要な文書、選択範囲、検索条件などが満たされていません。
無効な項目は、メニュー上で選択できない状態になります。

## [ファイル]

ファイルの作成、読み込み、保存、印刷を行います。各操作の詳細は
[4. 機能別解説](04_features.html) で説明します。

| 項目 | 説明 | 既定のショートカット |
| ---- | ---- | ---- |
| [新規作成] | 空の新しい文書を作成します。新規文書は編集可能な状態で開きます。 | - |
| [開く] | ファイルを読み込み、新しいドキュメントウィンドウに表示します。 | - |
| [閉じる] | アクティブなドキュメントウィンドウを閉じます。 | `Ctrl+F4` |
| [上書き保存] | 現在のファイルへ文書の内容を保存します。 | - |
| [名前を付けて保存] | 指定した別のファイルへ文書の内容を保存します。 | - |
| [ダンプイメージの保存] | アドレス、16進データ、文字データを整形したテキストをファイルへ保存します。 | - |
| [印刷] | 文書の内容を印刷します。 | - |
| [印刷プレビュー] | 印刷時のレイアウトを画面で確認します。 | - |
| [範囲を指定して印刷] | 印刷する範囲を指定してから、印刷または印刷プレビューを実行します。 | - |
| [プリンタの設定] | 印刷に使用するプリンタを設定します。 | - |
| [最新のファイル] | 最近開いたファイルの一覧を表示します。項目を選ぶと、そのファイルを開きます。 | - |
| [終了] | StirHex を終了します。 | - |

保存前のバックアップを作成する設定が有効な場合は、保存処理の前にバックアップが作成されます。

## [編集]

文書データの編集、クリップボード操作、選択範囲の操作を行います。基本的な編集操作は
[4. 機能別解説](04_features.html) で説明します。

| 項目 | 説明 | 既定のショートカット |
| ---- | ---- | ---- |
| [元に戻す] | 直前の編集を取り消します。取り消せる編集がない場合、または編集禁止中は無効です。 | `Ctrl+Z` |
| [やり直し] | 取り消した編集をもう一度適用します。やり直せる編集がない場合、または編集禁止中は無効です。 | `Ctrl+Shift+Z` |
| [切り取り] | 選択範囲を Windows のクリップボードへテキストとしてコピーすると同時に、内部のバイナリクリップボードにも保持し、その後で選択範囲を削除します。選択範囲がない場合、または編集禁止中は無効です。 | `Ctrl+X` |
| [コピー] | 選択範囲を Windows のクリップボードへテキストとしてコピーすると同時に、内部のバイナリクリップボードにも保持します。選択範囲がない場合は無効です。 | `Ctrl+C`／`Ctrl+Insert` |
| [貼り付け] | 内部のバイナリクリップボードの内容だけを貼り付けます。他のアプリでコピーした内容は貼り付けできません。選択範囲がある場合は選択範囲を置換し、選択範囲がない場合は設定に応じて挿入または上書きします。内部のバイナリクリップボードが空の場合、または編集禁止中は無効です。 | `Ctrl+V`／`Shift+Insert` |
| [16進テキスト貼り付け] | Windowsのクリップボードにあるテキストを16進表記として読み取り、バイトデータとして貼り付けます。貼り付けかたは[貼り付け]と同じです。クリップボードにテキストがない場合、または編集禁止中は無効です。この項目は移植版で追加した機能です。 | - |
| [選択範囲の削除] | 選択範囲のデータを削除します。選択範囲がない場合、または編集禁止中は無効です。 | - |
| [選択範囲の初期化] | 選択範囲を指定した1バイトの値で埋めます。選択範囲がない場合、または編集禁止中は無効です。 | - |
| [編集前に戻す] | 保存済みファイルを読み直し、保存後の編集内容を破棄します。変更済みでファイル名があり、編集可能な場合に使用できます。 | - |
| [全て選択] | 文書全体を選択します。データが空の場合は無効です。 | - |
| [構造体編集] | 構造体編集バーを表示または非表示にします。詳細は [5. 構造体編集](05_struct.html) で説明します。 | - |
| [編集禁止] | 編集可能と編集禁止を切り替えます。ロック状態の文書では無効です。 | - |

`[コピー]` は読み取り専用の文書でも、選択範囲があれば使用できます。

## [検索・移動]

検索、置換、比較、キャレットの移動、マーク操作を行います。検索と比較の詳細は
[4. 機能別解説](04_features.html) で説明します。

| 項目 | 説明 | 既定のショートカット |
| ---- | ---- | ---- |
| [検索] | 検索条件を指定するダイアログを開きます。 | `Ctrl+F` |
| [不一致検索] | 指定したバイト値と一致しないデータを検索します。 | - |
| [前検索] | 直前の検索条件を使い、現在位置より前を検索します。直前の検索条件がない場合は検索ダイアログが開きます。 | `Shift+F3` |
| [次検索] | 直前の検索条件を使い、現在位置より後ろを検索します。直前の検索条件がない場合は検索ダイアログが開きます。 | `F3` |
| [置換] | 検索したデータを別のデータへ置き換えるダイアログを開きます。編集禁止中は無効です。 | - |
| [比較] | 開いている2つの文書を比較し、相違箇所を表示します。文書が2つ未満の場合は無効です。 | - |
| [シンクロスクロール] | 複数の文書ウィンドウを登録し、スクロール位置を同期する設定を開きます。 | - |
| [データ先頭に移動] | キャレットをデータの先頭へ移動します。 | `Ctrl+Home` |
| [指定アドレスへ移動] | 指定したアドレスへキャレットを移動するダイアログを開きます。 | - |
| [最終変更箇所へ移動] | 最後に変更した位置へキャレットを移動します。変更履歴がない場合は無効です。 | - |
| [データ末尾に移動] | キャレットをデータの末尾へ移動します。 | `Ctrl+End` |
| [マークの登録／解除] | キャレット位置のマークを登録または解除します。キャレットがデータ末尾の後ろにある場合は無効です。 | - |
| [前のマーク位置] | 現在位置より前にあるマークへ移動します。マークがない場合は無効です。 | - |
| [次のマーク位置] | 現在位置より後ろにあるマークへ移動します。マークがない場合は無効です。 | - |
| [全てのマークの解除] | 登録されているマークをすべて解除します。マークがない場合は無効です。 | - |
| [マーク一覧] | 登録されているマークを一覧表示します。 | - |
| [BGREP] | 指定したフォルダー内のファイルを横断検索し、結果をアウトプットペインへ表示します。 | - |

検索結果が見つからない場合の表示は、環境設定で変更できます。

## [設定]

表示、入力、各種バー、アプリケーションの動作を設定します。設定ダイアログの詳細は
[6. 環境設定](06_env.html) と [7. 拡張子別設定](07_ext.html) で説明します。

| 項目 | 説明 | 既定のショートカット |
| ---- | ---- | ---- |
| [環境設定] | ツールバー、ステータスバー、キーアサイン、Undo の動作など、アプリケーション全体の設定を行います。詳細は [6. 環境設定](06_env.html) で説明します。 | - |
| [拡張子別設定] | 拡張子ごとの表示、入力、編集の初期設定を行います。詳細は [7. 拡張子別設定](07_ext.html) で説明します。 | - |
| [キャラクターセット] | 文字領域で使用する文字セットのサブメニューを開きます。 | - |
| [ASCII] | 文字領域を ASCII として表示し、入力を変換します。文書を開いていない場合は無効です。 | - |
| [SHIFT-JIS] | 文字領域を SHIFT-JIS として表示し、入力を変換します。文書を開いていない場合は無効です。 | - |
| [EUC] | 文字領域を EUC として表示し、入力を変換します。文書を開いていない場合は無効です。 | - |
| [Unicode] | 文字領域を Unicode として表示し、入力を変換します。文書を開いていない場合は無効です。 | - |
| [UTF-8] | 文字領域を UTF-8 として表示し、入力を変換します。文書を開いていない場合は無効です。この項目は移植版で追加した機能です。 | - |
| [EBCDIC] | 文字領域を EBCDIC として表示し、入力を変換します。文書を開いていない場合は無効です。 | - |
| [EBCIDK] | 文字領域を EBCIDK として表示し、入力を変換します。文書を開いていない場合は無効です。 | - |
| [バイトオーダー] | Unicode の2バイトデータを解釈するバイト順のサブメニューを開きます。 | - |
| [リトルエンディアン] | Unicode の2バイトデータをリトルエンディアンとして解釈します。文書を開いていない場合は無効です。 | - |
| [ビッグエンディアン] | Unicode の2バイトデータをビッグエンディアンとして解釈します。文書を開いていない場合は無効です。 | - |
| [アウトプット] | アウトプットペインを表示または非表示にします。表示中はチェック状態になります。 | - |
| [ビットイメージ] | ビットイメージバーを表示または非表示にします。表示中はチェック状態になります。 | - |
| [構造体編集] | 構造体編集バーを表示または非表示にします。詳細は [5. 構造体編集](05_struct.html) で説明します。 | - |

キャラクターセットとバイトオーダーの項目は、アクティブな文書がない場合に無効になります。

設定項目を変更して確定すると、対応する表示や入力の状態が更新されます。
設定の保存先については [1. はじめに](01_intro.html) を参照してください。

## [ウィンドウ]

複数のドキュメントウィンドウの配置を変更します。これらの項目に既定のショートカットは確認できませんでした。

| 項目 | 説明 | 既定のショートカット |
| ---- | ---- | ---- |
| [新しいウィンドウを開く] | アクティブな文書を新しいドキュメントウィンドウで表示します。 | - |
| [重ねて表示] | 開いているドキュメントウィンドウを重ねて配置します。 | - |
| [上下に並べて表示] | 開いているドキュメントウィンドウを上下に並べて配置します。 | - |
| [左右に並べて表示] | 開いているドキュメントウィンドウを左右に並べて配置します。 | - |
| [アイコンの整列] | 最小化されたドキュメントウィンドウのアイコンを整列します。 | - |
| [ウィンドウサイズ補正] | アクティブなドキュメントウィンドウの幅を表示内容に合わせて補正します。 | - |

## [ヘルプ]

ヘルプの表示とバージョン情報を確認します。

| 項目 | 説明 | 既定のショートカット |
| ---- | ---- | ---- |
| [ヘルプの表示] | 実行ファイルと同じフォルダーにある `help\index.html` を開きます。ファイルがない場合はエラーメッセージを表示します。 | `F1` |
| [バージョン情報] | StirHex のバージョン、著作権表示、非公式の移植版であることを表示します。 | - |
