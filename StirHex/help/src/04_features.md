# 4. 機能別解説

## ファイルの操作

### ファイルを開く・保存する

[ファイル]→[開く]でファイルを読み込みます。読み込みが完了すると、内容を表示するドキュメントウィンドウが作成されます。

[上書き保存]は、現在のファイル名へ内容を書き込みます。[名前を付けて保存]は、指定した別のファイル名へ内容を書き込みます。

ファイルを読み込むと、StirHex は読み込み時点のファイル更新日時を記録します。後で同じファイルを保存したときは、保存後の更新日時を次回の外部変更確認の基準にします。

保存前のバックアップは、[環境設定]のファイル設定で指定できます。[バックアップファイルの作成]が有効な場合、既存ファイルを保存する前にバックアップを作成します。

バックアップの世代数が1の場合は、元のファイル名に `.bak` を付けたファイルが作成されます。世代数を増やすと、古いバックアップは `.bk1`、`.bk2` などの名前で繰り下げられます。

[バックアップフォルダの指定]を有効にすると、バックアップは指定したフォルダーに作成されます。指定を無効にした場合は、保存対象のファイルと同じフォルダーが使われます。

移植版では、保存時の一時ファイルを作成してから元のファイルと置き換える方式は未実装です。保存時は、保存先のファイルを通常の書き込み方法で作成または上書きします。

### ダンプイメージを保存する

[ファイル]→[ダンプイメージの保存]を選ぶと、バイナリデータを整形したテキストファイルとして保存できます。データが空の場合は保存処理を実行しません。

ファイル名がある文書では、既定の出力ファイル名として元の拡張子を `.DMP` に置き換えた名前が設定されます。名前のない文書では、文書名に `.DMP` を付けた名前が設定されます。

保存ダイアログには、次の項目があります。

| 項目 | 内容 |
| ---- | ---- |
| [出力ファイル名] | ダンプを書き込むファイル名を指定します。 |
| [出力範囲] | ダンプする範囲の指定方法を選びます。 |
| [データ全体] | 文書の先頭から末尾までを出力します。 |
| [範囲指定] | 指定した開始アドレスから終了アドレスまでを出力します。 |
| [OK] | 指定を確定して保存を開始します。 |
| [キャンセル] | 保存を取り消します。 |

[範囲指定]を選ぶと、開始アドレスと終了アドレスを入力できます。アドレスの範囲は両端を含みます。

現在、選択範囲がある場合は、範囲指定欄の[選択範囲]が初期状態で有効になります。この項目を有効にすると、現在の選択範囲が使われ、開始アドレスと終了アドレスの入力欄は無効になります。

[選択範囲]を無効にすると、2つの入力欄へ直接アドレスを入力できます。[アドレスベース]の[10進]または[16進]を選ぶと、入力と有効範囲の表示が切り替わります。

開始アドレスが終了アドレスより大きい場合は、2つの値を入れ替えて範囲を確定します。入力が空、不正な基数、または文書の範囲外の場合は、ダイアログを閉じずにエラーメッセージを表示します。

既存のファイルを指定して[OK]を押した場合は、上書き確認が表示されます。上書きを選ばなければ、保存ダイアログは閉じません。

出力は、アドレス欄、16進データ欄、文字欄の順に並ぶ整形テキストです。先頭には列見出しと区切り線が出力されます。

各データ行は、アドレス、1行分の16進データ、2個の空白、文字データ、末尾の空白の順で構成され、行末は改行になります。

16進データは大文字の2桁表記です。アドレスの10進表示・16進表示は、データ表示で選んでいるアドレスの基数に従います。

文字欄は、現在の文字セットとバイトオーダーに従って作成されます。指定範囲が行の途中から始まる場合や、最終行にデータがない場合は、対応する欄が空白で埋められます。

範囲は、ダンプ保存ダイアログの入力欄または現在の[選択範囲]で指定します。

### ファイルの排他制御

[環境設定]の[ファイルの排他制御]では、開いているファイルを他のプロセスからどのように共有するかを選べます。

| 項目 | 開いている間に他のプロセスができること |
| ---- | ---- |
| [しない] | StirHex は排他用のハンドルを保持しません。 |
| [書き込み禁止] | 読み込みは許可しますが、書き込みは許可しません。 |
| [読み書き禁止] | 読み込みも書き込みも許可しません。 |

[書き込み禁止]または[読み書き禁止]を選ぶと、ファイルを開いた後から文書を閉じるまで、設定に応じたロックを保持します。

保存するときは、現在のロックを一時的に解放して書き込み、保存後に保存先を再びロックします。保存処理が失敗した場合も、ロックの再取得を試みます。

ロックの取得に失敗した場合、StirHex はそのファイルのロックを保持しません。外部プロセスがすでにファイルをロックしている場合などは、この状態になることがあります。

### 外部で変更されたファイルを扱う

開いている文書がアクティブになったとき、StirHex は記録している更新日時とディスク上の更新日時を比較します。異なる場合に、外部でファイルが変更されたと判断します。

この確認は文書がアクティブになったときに行われます。バックグラウンドで内容を常時監視する処理ではありません。

変更が検知されると、次の選択肢を持つダイアログが表示されます。

| 項目 | 動作 |
| ---- | ---- |
| [変更を無視して作業を続ける] | 現在の編集内容を残して作業を続けます。現在のディスク上の更新日時を次回確認の基準にします。 |
| [現在編集中の内容を破棄して再読み込みする] | 現在の編集内容を破棄し、ディスク上のファイルを読み直します。 |
| [現在編集中の内容を別ファイルに保存する] | 現在の編集内容を指定した別ファイルへ保存します。 |

[現在編集中の内容を破棄して再読み込みする]を選ぶと、再読み込み後にキャレットは先頭へ移動し、選択範囲と編集履歴は破棄されます。

[現在編集中の内容を別ファイルに保存する]を選んだ場合だけ、[ファイル名]、ファイル名を選ぶ操作、[変更されたファイルをオープンして比較実行]が有効になります。

別ファイルへの保存が完了すると、文書は保存先のファイルを現在のファイルとして扱います。[変更されたファイルをオープンして比較実行]を有効にしていた場合は、変更前のファイルを開いて比較します。

## カーソル移動と選択範囲

### 指定アドレスへ移動する

[検索・移動]→[指定アドレスへ移動]を選ぶと、[指定アドレスへ移動]ダイアログが表示されます。

[アドレス]には、数字だけのアドレスを入力します。基数が16進の場合は、数字と `A`～`F`（大文字・小文字）を使えます。前後の空白、`0x` などの接頭辞、基数にない文字は使えません。

[アドレスベース]の[10進]または[16進]で、入力する数値の基数を選びます。基数を変更すると、入力済みの値も選んだ基数で表示し直されます。

先頭に符号を付けない場合は、文書の先頭を0とする絶対アドレスへ移動します。先頭に `+` を付けると現在位置から前方へ、`-` を付けると現在位置から後方へ相対移動します。

移動先は0から文書サイズまでです。文書サイズと同じアドレスは、データ末尾の後ろのキャレット位置として扱われます。相対移動で範囲を超える値を指定した場合は、エラーメッセージを表示して移動しません。

移植版では、前方への相対移動に原版の256 MB上限を設けていません。文書サイズの範囲内で指定できます。

### 範囲を指定して選択する

範囲選択を起動すると、[選択範囲の指定]ダイアログが表示されます。ダイアログ内の[選択範囲]には、開始アドレスと終了アドレスの2つの入力欄があります。

2つの入力欄の間には `～` が表示されます。指定範囲は両端を含むため、開始アドレスと終了アドレスが同じ場合は1バイトを選択します。

現在の選択範囲がある場合は、[選択範囲]を有効にして、その範囲を入力欄へ反映できます。反映中はアドレス入力欄と[アドレスベース]が無効になります。

入力欄を使う場合は、[アドレスベース]の[10進]または[16進]を選びます。入力できる範囲は、データの先頭から末尾までです。文書サイズと同じ値は選択範囲の端点には指定できません。

開始アドレスが終了アドレスより大きい場合は、値を入れ替えて選択します。不正な入力や範囲外の入力では、エラーメッセージを表示してダイアログを閉じません。

### マークを登録・解除する

マークは、データ上のバイト位置に付ける目印です。1つの位置には、`MARK1`、`MARK2`、`MARK3` のいずれか1つを登録できます。

[マークの登録／解除]は、キャレット位置のマーク1を切り替えます。マークがない位置では登録し、同じ種類のマークがある位置では解除します。別の種類のマークがある位置では、マークの種類を変更します。

キャレットがデータ末尾の後ろにある場合は、マークを登録できません。

[マーク一覧]の末尾にある[＜マークの新規登録＞]を選ぶと、新しいマークのアドレスと色を指定できます。登録済みの行を選んで[編集]を押すと、アドレスまたは色を変更できます。

マークのアドレスを指定するダイアログには、[アドレス]、[マーク色]、[アドレスベース]、[10進]、[16進]があります。[マーク色]では `MARK1`、`MARK2`、`MARK3` を選びます。

マークのアドレスには、データの先頭から末尾までを指定できます。前後の空白や相対移動の符号は使えません。基数は[アドレスベース]で切り替えます。

### マークへ移動・一覧を使う

[前のマーク位置]は現在位置より前のマークへ移動し、[次のマーク位置]は現在位置より後ろのマークへ移動します。端まで到達すると、反対側の端にあるマークへ回り込みます。

マークが1つも登録されていない場合、前後のマークへの移動と[全てのマークの解除]は無効です。[全てのマークの解除]は登録済みのマークをすべて削除します。

[マーク一覧]には、マークの種類を示す色付きの番号と、アドレスが昇順で表示されます。[実行]を押すと選択したマークへ移動します。マークの行をダブルクリックしても移動します。

[解除]は一覧で選択したマークだけを削除し、[全解除]はすべてのマークを削除します。[閉じる]は一覧を閉じます。データがある場合は、一覧の末尾に新しいマークを登録する行が表示されます。

マーク1～3の文字色は白です。初期状態の背景色は、マーク1が紫、マーク2が緑、マーク3が水色です。これらの色は拡張子別設定の色として保存されます。

マークの位置はファイルの内容や設定として保存されません。文書を再読み込みすると、登録済みのマークは消去されます。

### 編集に伴うマークの移動

[ダイナミックマーク]を有効にすると、挿入や削除に合わせて、変更位置より後ろのマークが移動します。

削除範囲内のマークは消去されます。上書き編集ではデータの長さが変わらないため、マークは移動しません。

[ダイナミックマーク]を無効にすると、挿入や削除を行ってもマークの位置は移動しません。

## データの編集

編集操作は、文書が編集可能な状態でだけ実行できます。編集禁止中は、入力、削除、初期化、貼り付けなどのデータ変更操作が無効になります。

### 選択範囲を削除する

[編集]→[選択範囲の削除]は、選択範囲のバイトを削除します。選択範囲がない場合や編集禁止中は無効です。

削除後は、キャレットが削除前の選択範囲の先頭へ移動し、選択が解除されます。削除は1回の元に戻す操作の対象になります。

### 選択範囲を初期化する

[編集]→[選択範囲の初期化]は、選択範囲を同じ1バイトの値で埋めます。選択範囲がない場合や編集禁止中は無効です。

実行すると、[指定範囲の初期化]ダイアログが表示されます。範囲表示には、初期化する開始アドレスと終了アドレスが表示されます。

[初期化データ]には、0～`FF`の1バイトを16進数で入力します。入力欄は2文字までです。空欄や16進数以外の入力では、エラーメッセージを表示して確定しません。

[OK]を押すと、指定した値で選択範囲を初期化します。[キャンセル]を押すと、データを変更せずに戻ります。

初期化後は選択が解除され、キャレットは初期化した範囲の末尾の後ろへ移動します。初期化全体が1回の元に戻す操作の対象になります。

### 編集前の状態へ戻す

[編集]→[編集前に戻す]は、保存済みファイルを読み直して、保存後の編集内容を破棄します。

この項目は、ファイル名があり、変更があり、編集可能な文書でだけ使用できます。実行前に「編集内容を破棄してファイルを再読み込みします」という確認が表示されます。

確認するとファイルを読み直し、キャレットを先頭へ戻します。選択範囲、元に戻す履歴、やり直し履歴、マークも読み直し時に破棄されます。

### クリップボードを使う

[コピー]は、選択範囲をWindowsのクリップボードへテキストとしてコピーすると同時に、StirHex内部のバイナリクリップボードにも保持します。16進領域からコピーした場合は、空白で区切った大文字の16進表記がテキストになります。

文字領域からコピーした場合は、選択したバイト列をテキスト形式としてWindowsのクリップボードへ渡します。コピーは編集禁止中でも、選択範囲があれば実行できます。

[切り取り]は、選択範囲をWindowsのクリップボードへテキストとしてコピーし、内部のバイナリクリップボードにも保持した後、選択範囲を削除します。削除できない場合は、クリップボードの内容も変更しません。

[貼り付け]が使うのは、StirHex内部のバイナリクリップボードだけです。他のアプリでコピーした内容は貼り付けできません。内部のバイナリクリップボードが空の場合、[貼り付け]は無効です。

選択範囲がある場合、[貼り付け]は選択範囲を貼り付けデータで置き換えます。挿入にはなりません。置き換え後は選択が解除され、キャレットは貼り付けデータの末尾の後ろへ移動します。

選択範囲がない場合は、通常はキャレット位置へデータを挿入します。上書きモードで、[上書モード時の貼り付けは上書き処理する]が有効で、キャレットがデータ末尾より前にある場合は、キャレット位置から既存データを置き換えます。

上書き処理では、既存データの残りが貼り付けデータより短い場合、その残りだけを置き換えて、貼り付けデータの後半を末尾へ追加します。上記の条件に該当しない場合は、挿入として処理します。

貼り付けによる置換または挿入は、1回の元に戻す操作の対象になります。

## 検索と置換

### 検索ダイアログ

[検索・移動]→[検索]を選ぶと、[検索]ダイアログが表示されます。検索データは、16進データまたは文字列として指定します。

| 項目 | 内容 |
| ---- | ---- |
| [検索データ] | 検索するデータを入力します。 |
| [データ種別] | [16進データ]または[文字列]を選びます。 |
| [検索範囲] | 検索する範囲を選びます。 |
| [カーソル位置から] | 現在のキャレット位置を基準に検索します。 |
| [データ全体] | 文書全体を検索します。 |
| [選択範囲内] | 現在の選択範囲だけを検索します。選択範囲がない場合は無効です。 |
| [前検索] | 現在位置より前方を検索します。 |
| [次検索] | 現在位置より後方を検索します。 |
| [閉じる] | 検索ダイアログを閉じます。 |

[16進データ]では、16進数を2桁ずつ入力します。`AABB` のように連続して入力するか、`AA BB` のように半角スペースで区切ります。

16進数には `0`～`9` と `A`～`F`（大文字・小文字）を使えます。奇数桁、1バイトに満たない区切り、16進数以外の文字は入力できません。

[文字列]では、入力した文字列を現在の文書のキャラクターセットに従うバイト列へ変換して検索します。入力した文字をそのまま比較するのではなく、変換後のバイト列を比較します。

検索には、大文字と小文字を区別しない設定はありません。文字列検索でも、大文字と小文字に対応するバイトが異なれば別のデータとして扱います。

検索データにワイルドカードを指定する書式はありません。特定のバイトを無視する指定もありません。検索対象は、入力から作成された連続したバイト列です。

### 検索範囲と検索方向

[カーソル位置から]を選んだ場合、[次検索]はキャレットより後ろ、[前検索]はキャレットより前から検索します。検索は範囲の端で終了し、反対側へ回り込みません。

[データ全体]を選んだ場合、最初の[次検索]はデータ先頭から、最初の[前検索]はデータ末尾から検索します。2回目以降は、見つかった位置を基準に検索を続けます。

[選択範囲内]を選んだ場合、最初の検索で対象範囲が確定します。検索結果によって選択範囲が変わっても、同じ検索セッション中は対象範囲を変更しません。

一致すると、一致したバイト列が選択され、キャレットが一致位置へ移動します。画面外で一致した場合は、一致箇所が見える位置へスクロールします。

直前の検索条件があるとき、[前検索]／[次検索]は検索ダイアログを開かずに同じ条件で繰り返します。直前の検索条件がないときは、検索ダイアログが開きます。

検索結果がない場合は、通常はビープ音が鳴ります。[環境設定]の[検索で見つからなかった場合にメッセージを表示する]を有効にすると、メッセージが表示されます。

### 不一致検索

[検索・移動]→[不一致検索]を選ぶと、[不一致検索]ダイアログが表示されます。指定した1バイトと一致しない最初のバイトを検索します。

[不一致パターン]には、1～2桁の16進数を入力します。`0A` のように2桁へ正規化され、3桁以上や16進数以外の入力は確定できません。

[検索範囲]には、[カーソル位置から]、[データ全体]、[選択範囲内]があります。[選択範囲内]は、選択範囲がある場合だけ選べます。

[前検索]と[次検索]の動作は通常の検索と同じです。一致しないバイトが見つかると、その1バイトが選択されます。

不一致検索には文字列入力、大文字小文字の指定、ワイルドカード、無視するバイトの指定はありません。

### 置換ダイアログ

[検索・移動]→[置換]を選ぶと、[置換]ダイアログが表示されます。検索するデータと置き換えるデータを、それぞれ16進データまたは文字列で指定します。

| 項目 | 内容 |
| ---- | ---- |
| [検索データ] | 置換対象を指定します。 |
| [データ種別] | 検索データの[16進データ]または[文字列]を選びます。 |
| [置換データ] | 置き換え後のデータを指定します。 |
| [データ種別] | 置換データの[16進データ]または[文字列]を選びます。 |
| [置換範囲] | [カーソル位置から]、[データ全体]、[選択範囲内]から選びます。 |
| [前検索] | 一致箇所を前方へ探し、確認後に置換します。 |
| [次検索] | 一致箇所を後方へ探し、確認後に置換します。 |
| [一括置換] | 指定範囲内の一致箇所を確認なしで置換します。 |
| [閉じる] | 置換を実行せずに閉じます。 |

検索データの入力規則は[検索]ダイアログと同じです。文字列の検索データと置換データは、現在のキャラクターセットに従ってバイト列へ変換します。

[置換データ]を空欄にすると、検索データを削除するかどうかを確認します。削除を選ぶと、検索データを空のバイト列へ置き換えます。

[置換範囲]の[選択範囲内]は、選択範囲がある場合だけ選べます。選択範囲がない場合、置換対象はキャレット位置または文書全体になります。

置換は編集操作です。編集禁止中は実行できません。

### 置換の確認

[前検索]または[次検索]で置換を開始すると、一致箇所ごとに[置換確認]ダイアログが表示されます。

| 項目 | 動作 |
| ---- | ---- |
| [実行] | 現在表示されている一致箇所を置換します。 |
| [スキップ] | 現在の一致箇所を変更せず、次の一致箇所へ進みます。 |
| [一括置換] | 現在位置以降の残りを確認なしで置換します。 |
| [キャンセル] | 置換を中止します。 |

[実行]で置換した後は、[次検索]なら置換後のデータの後ろから、[前検索]なら置換位置の前から検索を続けます。

[一括置換]を実行すると、置換が完了した件数をメッセージで表示します。置換されたデータは元に戻す操作の対象になります。

### 比較

[検索・移動]→[比較]は、開いている2つの文書を比較します。比較対象として、現在の文書以外に開いている文書を選びます。

開いている文書が2つ未満の場合は、[比較]を実行できません。空の文書を含む場合も比較結果は作成しません。

文書サイズが異なる場合は、サイズが小さい文書の長さまでを比較します。サイズが異なることを知らせるメッセージが先に表示されます。

相違があると、両方の文書に相違範囲が設定され、[相違箇所一覧]が表示されます。相違がない場合は、比較表示を解除します。

[相違箇所一覧]には、相違範囲が昇順で表示されます。列は[相違箇所]、[相違終了箇所]、[相違サイズ]です。アドレスとサイズは16進数で表示されます。

1バイトだけの相違では、[相違終了箇所]は空欄になります。複数バイトの相違では、開始アドレス、終了アドレス、範囲の長さが表示されます。

相違範囲は、データ領域の比較結果色で強調されます。相違一覧を閉じると、比較結果の強調とシンクロスクロールが解除されます。

### 相違箇所一覧を使う

| 項目 | 動作 |
| ---- | ---- |
| [比較結果の強調表示] | 2つの文書で相違範囲を強調表示するか切り替えます。初期状態は有効です。 |
| [シンクロスクロール] | 2つの文書のスクロールを連動するか切り替えます。初期状態は有効です。 |
| [切替] | ジャンプ先にする文書を切り替えます。 |
| [ジャンプ] | 選択した相違範囲へ移動します。 |
| [閉じる] | 相違一覧を閉じ、比較状態を解除します。 |

相違一覧の行をダブルクリックしても、その相違範囲へ移動します。[切替]を使うと、同じ相違範囲をもう一方の文書で確認できます。

### シンクロスクロール

[検索・移動]→[シンクロスクロール]は、複数のドキュメントウィンドウの縦スクロールを連動させます。開いているウィンドウが2つ未満の場合は、ダイアログを表示しません。

ダイアログには、次の2つの一覧があります。

| 項目 | 内容 |
| ---- | ---- |
| [シンクロしないウィンドウ] | 現在、同期していないウィンドウの候補です。 |
| [シンクロするウィンドウ] | 同期対象として登録したウィンドウです。 |
| [↓追加] | 選択した候補を同期対象へ移します。 |
| [↑解除] | 選択した同期対象を候補へ戻します。 |
| [全解除] | すべての同期対象を候補へ戻します。 |
| [OK] | 現在の登録内容を同期グループとして確定します。 |
| [キャンセル] | 登録内容を反映せずに閉じます。 |

同期グループに登録すると、グループ内のウィンドウで縦スクロールが伝わります。キャレット移動や検索によるスクロールも、同期対象へ伝わります。

相違一覧の[シンクロスクロール]は、比較中の2つの文書だけを対象にした同期の切り替えです。手動登録した同期グループとは別に設定できます。

### BGREP

[検索・移動]→[BGREP]は、指定したフォルダー内の複数ファイルを横断検索します。検索結果はアウトプットペインへ追加されます。

| 項目 | 内容 |
| ---- | ---- |
| [検索データ] | 検索する16進データまたは文字列を入力します。 |
| [データ種別] | [16進データ]または[文字列]を選びます。 |
| [検索するファイルの種類] | セミコロンで区切ったワイルドカードを指定します。例: `*.bin;*.dat`。 |
| [フォルダ] | 検索を開始するフォルダーを指定します。 |
| [サブフォルダも検索する] | 下位のフォルダーも検索します。 |
| [システム属性ファイルは検索しない] | システム属性が付いたファイルを検索対象から外します。 |
| [OK] | 指定を確定して検索を開始します。 |
| [キャンセル] | BGREPを開始せずに閉じます。 |

[文字列]を選ぶと、文字列用のキャラクターセットを選べます。キャラクターセットは[ASCII]、[SHIFT-JIS]、[EUC]、[Unicode]、[EBCDIC]、[EBCIDK]です。[16進データ]ではキャラクターセットの選択は使いません。

[検索するファイルの種類]は、1つのファイル名パターンまたは複数のパターンをセミコロンで区切って指定します。空欄の場合はすべてのファイルを対象にします。

検索フォルダーが存在しない場合は、BGREPを開始できません。検索中は[BGREP検索状況]ダイアログに、現在の[検索ファイル ：]と[データ件数 ：]が表示されます。

検索結果は、ファイルのフルパスと8桁の16進オフセットを `ファイルパス : オフセット` の形式でアウトプットペインへ追加します。ファイルを開けない場合や空のファイルの場合は、アクセスできないファイルとして情報行が追加されます。

検索が完了すると、該当ファイルがない場合、結果がない場合、結果件数がある場合で、それぞれ集計メッセージが追加されます。[キャンセル]を押すと停止を要求し、走査完了後に状況ダイアログが閉じます。

アウトプットペインの結果行をダブルクリックするか、コンテキストメニューの[タグジャンプ]を選ぶと、該当ファイルを開いてヒット位置へ移動します。[検索結果のコピー]は表示中の全行をWindowsのクリップボードへテキストとしてコピーし、[クリア]は結果を消去します。

## 表示の切り替え

### ビットイメージ

[設定]→[ビットイメージ]で、アクティブな文書のバイト列を画像として表示します。1バイトを1ピクセルとして扱い、画像の幅は128ピクセルです。データが長い場合は縦方向に並び、縦スクロールで確認できます。

初期状態のパレットは、バイト値によって次のように色分けされます。

| バイト値 | 色 |
| ---- | ---- |
| `00` | 白 |
| `01`～`1F` | シアン |
| `20`～`7F` | 赤 |
| `80`～`FF` | 黒 |

ビットイメージを表示するときは、現在のアクティブ文書から画像を作り直します。ビットイメージ上のコンテキストメニューにある[最新イメージを表示]でも、現在の文書から作り直します。

[編集内容をリアルタイムでビットイメージに反映する]を有効にすると、表示中の画像がデータ編集後に更新されます。連続した編集は、メッセージ処理へ戻った時点でまとめて1回の再構築になります。

移植版では、更新時に表示中の画像を文書全体から再構築します。原版の増分更新とは異なります。

初期状態では、[編集内容をリアルタイムでビットイメージに反映する]は有効です。無効にした場合は、[最新イメージを表示]を選ぶまで編集内容は画像へ反映されません。

画像の色は、[拡張子別設定]の[色・フォント]にある[ビットイメージに指定色を反映させる]で切り替えられます。有効にすると、データの文字色と強調表示コードの色から256色のパレットを作ります。背景はデータの背景色になります。

ビットイメージには、マーク、比較結果、構造体編集範囲の色は重ねて表示されません。これらを画像へ反映する処理は実装されていません。

実装上、画像へ変換するデータ長は符号付き32ビット整数の範囲へ制限されています。約2 GBを超える文書の全体をビットイメージで表示する処理は未実装です。

ビットイメージ上へマウスポインターを移動すると、対応するバイトのオフセットがステータスバーに表示されます。画像の範囲外では通常のレディ表示に戻ります。

### キャラクターセット

[設定]→[キャラクターセット]では、文字領域の表示と文字入力に使う変換方法を選びます。現在の文書がない場合は、キャラクターセットの項目は無効です。

| 項目 | 文字領域の表示 | 文字入力 |
| ---- | ---- | ---- |
| [ASCII] | 印字可能なASCIIをそのまま表示し、それ以外を `.` で表示します。 | 入力バイトをそのまま保存します。 |
| [SHIFT-JIS] | ASCII、半角カナ、正しい2バイト文字を表示します。不正なバイトは `.` になります。 | CP932の1バイトまたは2バイト列として保存します。 |
| [EUC] | EUC-JPの主領域や半角カナを表示用の文字へ変換します。 | CP932の入力をEUC-JPのバイト列へ変換します。 |
| [Unicode] | 2バイトをUTF-16の文字として解釈し、表示用の文字へ変換します。 | 入力文字をUTF-16の2バイト列へ変換します。 |
| [EBCDIC] | EBCDICの変換表で表示用の文字へ変換します。変換できない値は `.` になります。 | 入力文字をEBCDICの逆変換表で保存します。 |
| [EBCIDK] | EBCIDKの変換表で表示用の文字へ変換します。変換できない値は `.` になります。 | 入力文字をEBCIDKの逆変換表で保存します。 |

2バイト文字は、表示上も2つのデータセルを使います。行末で2バイト文字が分かれる場合は、表示の位置を合わせるために空白セルが入ります。

文字列の検索・置換とBGREPでも、文字列を入力した場合は選択中のキャラクターセットでバイト列へ変換します。16進データの検索・置換には影響しません。

### バイトオーダー

[設定]→[バイトオーダー]の[リトルエンディアン]または[ビッグエンディアン]で、2バイト単位の解釈を切り替えます。

バイトオーダーは、Unicodeの文字領域で2バイトをUTF-16として解釈するときに影響します。ダンプ保存と印刷の文字領域でも、同じバイトオーダーが使われます。

ステータスバーに表示される2バイト値、4バイト値、`float`、`double`の値も、選択したバイトオーダーで組み立てられます。1バイト値の表示には影響しません。

ASCII、SHIFT-JIS、EUC、EBCDIC、EBCIDKの表示変換は、バイトオーダーを使いません。

移植版では、Unicodeの文字入力で作成する2バイト列はリトルエンディアンで保存されます。ビッグエンディアンを選んだ場合は表示・数値解釈がビッグエンディアンになりますが、入力時の保存順は変わりません。

### 強調表示

強調表示は、特定のバイト値に通常のデータ文字色とは別の文字色を割り当てる機能です。設定場所は[拡張子別設定]→[色・フォント]です。

[データ種別]から対象の色カテゴリを選ぶと、[文字色指定]と[背景色指定]でカテゴリの色を変更できます。データ全体の通常色は[データ]カテゴリで指定します。

[強調データ文字色指定]の一覧には、強調するバイト値と色が表示されます。[追加]でバイト値を指定して色を選び、[編集]で色を変更します。[削除]と[全削除]で登録を削除できます。

強調するバイト値は、[強調表示コード]ダイアログで1バイトの16進数として入力します。`00`～`FF`を指定でき、`0x` 接頭辞も入力できます。

登録した強調表示コードは、16進領域の該当バイトに指定した文字色を適用します。文字領域は通常のデータ文字色で表示されます。

強調表示コードと色は、拡張子別設定として保存されます。初期状態では強調表示コードは登録されていません。

## 印刷

### 印刷の種類

[ファイル]には、[印刷]、[印刷プレビュー]、[範囲を指定して印刷]があります。

[印刷]は文書全体を印刷します。[印刷プレビュー]は印刷前のページを画面で確認します。データが空の文書では、印刷を開始しません。

[範囲を指定して印刷]を選ぶと、[範囲を指定して印刷]ダイアログが表示されます。範囲を指定した後、[OK]で直接印刷へ進むか、[プレビュー経由で印刷]を有効にして印刷プレビューへ進みます。

範囲指定には、開始アドレスと終了アドレス、[選択範囲]、[アドレスベース]の[10進]・[16進]が使えます。現在の選択範囲がある場合は、[選択範囲]が初期状態で有効になります。

範囲は両端を含みます。入力が不正な場合は、範囲ダイアログを閉じずにエラーメッセージを表示します。

[印刷プレビュー]はメインウィンドウ全体に表示されます。プレビューを終了すると、文書ウィンドウが元のMDI配置へ戻ります。

### 印刷レイアウト

印刷内容は、アドレス領域、16進領域、文字領域からなる整形ダンプです。[１行当たりの表示バイト数]で指定したバイト数を1行に配置します。

1行の基本構成は、次の順です。

1. アドレス領域
2. バイトごとの2桁16進表記と区切り空白
3. 2個の区切り空白
4. 文字領域

1行当たりの表示バイト数が16の場合、アドレス11桁、16進領域48桁、区切り2桁、文字領域16桁で、合計77桁になります。表示バイト数を変更すると、16進領域と文字領域の幅も変わります。

各ページのデータの前には、アドレス列とバイト列の見出しが印刷されます。見出しの下には区切り線があります。

ページ上部の左側にはファイル名が印刷されます。右側には印刷時点の日付が印刷されます。

ページ下部の中央には、現在のページ番号と総ページ数が `- 現在ページ/総ページ数 ` の形式で印刷されます。右下には現在のキャラクターセット名が印刷されます。

データ領域の周囲には枠線があります。ページの先頭がデータ行の途中になる場合は、先頭側のデータ欄を空白で埋めて列を合わせます。

印刷範囲を指定した場合も、ページ単位の行境界に合わせて配置します。指定範囲外のセルは空白になります。

印刷色は白黒です。通常のデータは黒文字・白背景で印刷し、比較中の相違範囲だけ白文字・黒背景で反転します。

マーク、選択範囲の反転、構造体編集範囲の色、拡張子別設定の強調表示色は印刷へ反映されません。

### 印刷フォント

印刷には、固定幅の「ＭＳ 明朝」を使います。文字サイズは10ポイント、太字ではない通常の太さです。

印刷フォントはプリンターの解像度に合わせて作成されるため、画面上の文字サイズと印刷時の物理的な文字サイズは一致しません。

文字領域のデータ変換は、画面表示と同じキャラクターセットおよびバイトオーダーを使います。印刷フォントの文字セットはSHIFT-JISです。

印刷プレビューでも、印刷時と同じページ分割、ヘッダ、ページ番号、フォント、文字領域の変換が使われます。

## その他の機能

### 名前を指定して実行

[名前を指定して実行]はメニューバーにはありません。[設定]→[環境設定]の[キーアサイン]でキーへ割り当てるか、[ユーザーメニュー]へ登録して起動します。アクティブな文書がない状態でも起動できます。

ダイアログには、次の項目があります。

| 項目 | 内容 |
| ---- | ---- |
| [コマンドライン] | 実行するファイルのパスまたは文字列を入力します。入力欄は履歴コンボです。 |
| 履歴 | 過去に実行した入力を新しい順に表示します。最大10件です。 |
| [参照] | 実行するファイルをファイル選択ダイアログから指定します。 |
| [OK] | 入力を履歴へ追加し、ダイアログを閉じて実行します。 |
| [キャンセル] | 実行せずにダイアログを閉じます。 |

起動時の[コマンドライン]は空欄です。[参照]ではプログラムまたはすべてのファイルを選び、選んだパスを[コマンドライン]へ設定します。

[コマンドライン]が空欄のまま[OK]を押すと、エラーメッセージが表示され、ダイアログは閉じません。入力がある場合は、同じ入力が履歴の先頭へ追加されます。履歴内で大文字小文字を区別しない重複項目は取り除かれます。

入力文字列は分割されず、そのまま実行対象のファイルとしてシェルへ渡されます。独立した引数入力欄はなく、入力に引数を含めても引数として分離されないため、実行に失敗します。現在の文書のパスが引数へ自動的に追加されることもありません。

実行に失敗した場合は、入力した実行対象と失敗理由を含むエラーメッセージが表示されます。

### マーク２・マーク３の登録と解除

[マーク２登録／解除]と[マーク３登録／解除]はメニューバーにはありません。[キーアサイン]でキーへ割り当てるか、[ユーザーメニュー]へ登録して使います。

実行すると、キャレット位置のマーク2またはマーク3を切り替えます。マークがない位置では登録し、同じ種類のマークがある位置では解除し、別の種類のマークがある位置では種類を変更します。キャレットがデータ末尾の後ろにある場合は無効です。
